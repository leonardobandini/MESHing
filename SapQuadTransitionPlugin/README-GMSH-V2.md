# MESHing 3.0.6 — SAP2000 e CSiBridge

MESHing suddivide aree selezionate in elementi shell prevalentemente quadrangolari con Gmsh. La voce del menu è **Tools → MESHing**. Il nome tecnico della DLL e l'identità COM restano compatibili con le installazioni esistenti.

## Uso

1. Apri un modello già salvato e sbloccato in SAP2000 o CSiBridge 27+, seleziona le aree e, quando occorre, i nodi e i frame che devono vincolare la geometria. MESHing blocca il modello quando si apre: la selezione e la navigazione restano disponibili. Chiudendo MESHing, il modello inizialmente sbloccato torna sbloccato.
2. Imposta dimensioni e opzioni Gmsh. Ogni **Genera** crea prima il backup numerato se l'opzione è attiva, poi **salva sempre il modello corrente nel file SDB/BDB attivo**, crea la mesh e completa l'applicazione in memoria. FAST è automatico dove le tabelle lo supportano, con ripiego sul percorso compatibile. La finestra di avanzamento permette **Annulla generazione** appena la chiamata API in corso termina.
3. Controlla mesh e qualità: **Annulla mesh** riapre l'ultimo modello pre-mesh salvato, sia in SAP2000 sia in CSiBridge. Per una nuova generazione seleziona altre aree: compare una conferma OK/Annulla che avvisa del nuovo salvataggio e della sostituzione dell'Undo precedente, disattivabile per la sessione. Chiudere MESHing dopo Genera elimina la possibilità di Annulla; la mesh è ancora in memoria e chiudere il modello host senza salvarlo riapre lo stato su disco precedente all'ultimo Genera. Per conservare la mesh nel file occorre salvare esplicitamente nell'host.

Se apri MESHing su un modello nuovo **mai salvato**, compare un avviso: la finestra, le schede e la guida restano consultabili, ma **Genera**, **Annulla mesh** e **Qualità della mesh** non sono disponibili. Salva il modello in SAP2000/CSiBridge: MESHing riconosce il nuovo file SDB/BDB, blocca il modello e abilita Genera quando è selezionata almeno un'area.

La guida offline dettagliata è in `docs/help-gmsh-v2/index-it.html` (italiano) e `docs/help-gmsh-v2/index-en.html` (English); è raggiungibile anche con **F1** dalla finestra del plugin. Il backup numerato copia l'ultimo file SDB/BDB *già salvato prima di Genera*: non contiene le eventuali modifiche ancora in memoria, che vengono invece incluse nel salvataggio successivo. Con backup disattivato, Genera salva comunque il file attivo e sovrascrive il precedente stato su disco. Il backup è distinto dalla copia privata post-salvataggio per il ripristino. FAST importa la mesh attraverso le tabelle editabili quando disponibile; la modalità Standard usa le API degli oggetti. I fori O-grid usano archi circolari e mantengono i nodi del bordo al raggio richiesto.

Per le aperture definite da un gruppo di frame, i tratti sovrapposti ad altri frame selezionati conservano l'appartenenza al contorno del gruppo anche dopo la suddivisione dei segmenti. L'apertura deve comunque formare un contorno chiuso all'interno delle aree selezionate.

## Scaricare e compilare

- L'installer controlla il [Microsoft Visual C++ Redistributable x64 ufficiale](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist), versione **14.42.34226.3 o successiva compatibile**. Se manca, lo scarica direttamente da Microsoft, verifica la firma e avvia il setup Microsoft interattivo prima di installare MESHing; se è necessario riavviare Windows, ripeti poi l'installazione MESHing. Senza connessione, usa il link Microsoft per installarlo separatamente. Le DLL runtime Visual C++ Microsoft non sono incluse nello ZIP.
- Estrai lo ZIP e avvia **`MESHingSetup.exe`** o `install_MESHing.cmd`. La finestra bilingue mostra nome, descrizione e licenze GPL di MESHing/Gmsh con link ai testi e ai sorgenti inclusi nel pacchetto; mostra anche controllo delle applicazioni aperte, prerequisito e setup Microsoft, verifica, preparazione dei file, sostituzione sicura della versione precedente, registrazione e aggiornamento dei menu. La lingua iniziale è quella di Windows (italiano o inglese); **Lingua / Language** permette di sceglierla manualmente in qualsiasi momento. Se SAP2000 o CSiBridge è aperto, l'installazione resta bloccata finché le sessioni non vengono chiuse dall'utente; l'installer non chiude né salva i modelli.
- [Release MESHing 3.0.6](https://github.com/leonardobandini/MESHing/releases/tag/v3.0.6): ZIP versionato e [ZIP Latest](https://github.com/leonardobandini/MESHing/releases/latest/download/MESHing-latest.zip). Il controllo aggiornamenti nel piè di pagina consulta la release Latest.
- `SOURCE.md`, incluso nello ZIP, identifica il binario versionato MESHing 3.0.6, i sorgenti corrispondenti e i relativi checksum nella stessa release. Le istruzioni di build sono nell'archivio sorgenti, `packaging/SOURCE_BUILD.md`.

Il backend binario combinato con OpenSSL 3 (Apache-2.0) esercita l'opzione GPLv3. Le licenze degli altri componenti e l'eccezione limitata di Gmsh restano invariate: vedi `LICENSE-APPLICATION.md`, `GPL-3.0.txt`, `THIRD_PARTY_NOTICES.md` e `licenses/`.
